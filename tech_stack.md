# Tech Stack

## Teknologi utama

- **HTML5** — struktur semantik, navigasi, katalog, form, dan footer.
- **CSS3** — CSS variables, Grid, Flexbox, responsive breakpoint, visual card, texture, dan transisi.
- **Vanilla JavaScript** — menu mobile, filter kategori, preview produk, keranjang, validasi, kalkulasi, dan checkout.
- **Intl.NumberFormat** — format mata uang Rupiah `id-ID`.
- **WhatsApp URL API** — membuka pesan checkout melalui `https://wa.me/`.

## Batasan teknis

- Tidak menggunakan framework JavaScript.
- Tidak menggunakan backend atau database.
- Tidak menggunakan package manager atau dependency eksternal.
- Data keranjang hanya tersimpan selama halaman browser terbuka.
- Checkout dilakukan melalui link WhatsApp yang dibuat di sisi client.
