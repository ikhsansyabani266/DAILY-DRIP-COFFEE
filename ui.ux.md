# UI/UX Daily Drip Coffee

## Arah visual

Website menggunakan konsep **editorial coffee journal** seperti catatan harian kedai kopi:

- Hero fullscreen dengan foto bar dan headline minimal.
- Navbar overlay yang ringan.
- Serif untuk headline dan cerita brand.
- Sans-serif untuk teks pendukung.
- Monospace uppercase untuk label, kategori, harga, dan receipt.
- Palet espresso, caramel, cream, sand, dan orange.
- Layout About dua kolom dengan foto coffee shop dan panel informasi brand.
- Aksen orange, cream, tan, sand, dan dark brown digunakan konsisten di seluruh halaman.
- Visual utama memakai konsep warm editorial coffee journal.

## Alur pengalaman

```text
Start with coffee → Find your drip → Make it yours → The Daily Drip Story
```

## UX utama

- Navbar desktop dan drawer menu pada mobile.
- Filter menu berdasarkan empat kategori.
- Kartu produk mengubah preview saat dipilih.
- Tombol `+` pada preview menambahkan produk ke keranjang.
- Receipt menampilkan quantity, catatan, subtotal, diskon, dan total.
- Form checkout memiliki validasi inline.
- Ringkasan checkout menyediakan tombol WhatsApp.
- Layout tetap responsif tanpa mengubah struktur utama.

Prioritas desain adalah keterbacaan, ruang napas, alur scroll yang jelas, dan interaksi yang mudah dipahami.
